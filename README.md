# Manila Hotel Project - Hotel Web Application

ASP.NET MVC hotel website and management application tailored for a Manila property deployment.

## Overview
Guest-facing hotel pages and an internal management surface for rooms, content, and bookings.

## Key Features
- Hotel website pages (rooms, gallery, contact, policies)
- Booking / reservation oriented controllers and views
- Admin management screens
- Static assets and uploads for property media
- SQL Server data layer

## Tech Stack
- **Backend:** ASP.NET MVC (C#)
- **Frontend:** Razor views, JavaScript, CSS/Bootstrap
- **Database:** Microsoft SQL Server
- **Structure:** nested `ManilaHotelProject/` web application

## Getting Started
1. Open the solution under `ManilaHotelProject/`
2. Update connection strings
3. Restore packages, build, and run on IIS Express/IIS
